# 🔐 دليل نظام الصلاحيات - منصة التعليم الذكي

## نظرة عامة

تم تطبيق نظام صلاحيات شامل ومرن للتحكم في ما يمكن للمعلمين وأولياء الأمور والطلاب القيام به داخل المنصة.

---

## 📋 الوصول إلى إعدادات الصلاحيات

### للمشرف فقط:
1. تسجيل الدخول كمشرف
2. الذهاب إلى **إدارة الصلاحيات** 🔐 من القائمة الجانبية
3. اختيار الدور (معلم / ولي أمر / طالب)
4. تفعيل أو تعطيل الصلاحيات المطلوبة
5. حفظ التغييرات

**ملاحظة هامة:** المشرف يمتلك جميع الصلاحيات بشكل دائم ولا يمكن تقييده.

---

## 👨‍🏫 صلاحيات المعلمين

### 1. **إدارة الإعدادات الأكاديمية** (`canManageAcademicSettings`)
- **الوصف:** السماح للمعلم بإضافة وتعديل الصفوف والمواد والترمات والوحدات
- **التأثير:** 
  - إذا كانت مفعلة: يمكن للمعلم الوصول إلى صفحة "الإعدادات الأكاديمية"
  - إذا كانت معطلة: يظهر للمعلم رسالة "لا توجد صلاحية" 🔒

### 2. **تعديل الإعدادات العامة** (`canEditGeneralSettings`)
- **الوصف:** السماح للمعلم بسحب وتعديل الإعدادات الأكاديمية العامة من المشرف
- **التأثير:** نظام Copy-on-Write للإعدادات الأكاديمية

### 3. **إدارة المحتوى التعليمي** (`canManageContent`)
- **الوصف:** السماح للمعلم بربط المحتوى التعليمي (فيديو، أفاتار، تمارين)
- **التأثير:** 
  - إذا كانت مفعلة: يمكن للمعلم الوصول إلى صفحة "إدارة المحتوى"
  - إذا كانت معطلة: يظهر رسالة عدم الصلاحية

### 4. **إنشاء أولياء أمور** (`canCreateParents`)
- **الوصف:** السماح للمعلم بإنشاء حسابات جديدة لأولياء الأمور
- **التأثير:** 
  - إذا كانت مفعلة: يظهر زر "➕ إضافة ولي أمر"
  - إذا كانت معطلة: الزر مخفي

### 5. **تعديل أولياء أمور** (`canEditParents`)
- **الوصف:** السماح للمعلم بتعديل بيانات أولياء الأمور
- **التأثير:** 
  - إذا كانت مفعلة: يظهر زر "✏️ تعديل" لكل ولي أمر
  - إذا كانت معطلة: الزر مخفي

### 6. **حذف أولياء أمور** (`canDeleteParents`)
- **الوصف:** السماح للمعلم بحذف حسابات أولياء الأمور
- **التأثير:** 
  - إذا كانت مفعلة: يظهر زر "🗑️ حذف"
  - إذا كانت معطلة: الزر مخفي + رسالة تحذير عند المحاولة

### 7. **إنشاء طلاب** (`canCreateStudents`)
- **الوصف:** السماح بإنشاء حسابات جديدة للطلاب
- **التأثير:** 
  - إذا كانت مفعلة: يظهر زر "➕ إضافة طالب"
  - إذا كانت معطلة: الزر مخفي

### 8. **تعديل طلاب** (`canEditStudents`)
- **الوصف:** السماح بتعديل بيانات الطلاب
- **التأثير:** إظهار/إخفاء زر "✏️" للطلاب

### 9. **حذف طلاب** (`canDeleteStudents`)
- **الوصف:** السماح بحذف حسابات الطلاب
- **التأثير:** إظهار/إخفاء زر "🗑️" + منع الحذف مع تحذير

### 10. **عرض التقارير** (`canViewReports`)
- **الوصف:** السماح بعرض التقارير والإحصائيات
- **التأثير:** الوصول إلى صفحة التقارير

### 11. **إدارة الاختبارات** (`canManageQuizzes`)
- **الوصف:** السماح للمعلم بإنشاء وتعديل الاختبارات
- **التأثير:** الوصول إلى إدارة الاختبارات

---

## 👨‍👦 صلاحيات أولياء الأمور

### 1. **إنشاء أبناء** (`canCreateStudents`)
- **الوصف:** السماح بإنشاء حسابات للأبناء
- **التأثير:** 
  - إذا كانت مفعلة: يظهر زر "+ إضافة" في قائمة الأبناء
  - إذا كانت معطلة: الزر مخفي + رسالة تحذير عند المحاولة

### 2. **تعديل بيانات الأبناء** (`canEditStudents`)
- **الوصف:** السماح بتعديل بيانات الأبناء
- **التأثير:** إمكانية تعديل معلومات الطالب

### 3. **حذف أبناء** (`canDeleteStudents`)
- **الوصف:** السماح بحذف حسابات الأبناء
- **التأثير:** إظهار/إخفاء خيار الحذف

### 4. **عرض التقارير** (`canViewReports`)
- **الوصف:** السماح بعرض التقارير والإحصائيات
- **التأثير:** الوصول إلى تقارير الأداء

### 5. **تغيير الصف** (`canChangeGrade`)
- **الوصف:** السماح بتغيير الصف الدراسي للطالب
- **التأثير:** إظهار/إخفاء خيار تغيير الصف

### 6. **التواصل مع الدعم** (`canChatWithSupport`)
- **الوصف:** السماح بالتواصل مع الدعم الفني عبر الدردشة
- **التأثير:** إظهار/إخفاء نظام الدردشة

---

## 👨‍🎓 صلاحيات الطلاب

### 1. **تغيير الصف** (`canChangeGrade`)
- **الوصف:** السماح للطالب بتغيير صفه الدراسي
- **التأثير:** إظهار/إخفاء خيار تغيير الصف في الإعدادات

### 2. **الوصول للدردشة** (`canAccessChat`)
- **الوصف:** السماح للطالب بالوصول إلى نظام الدردشة
- **التأثير:** إظهار/إخفاء أيقونة وواجهة الدردشة 💬

### 3. **الوصول للقاءات المباشرة** (`canAccessLiveMeeting`)
- **الوصف:** السماح للطالب بالانضمام للقاءات المباشرة
- **التأثير:** إظهار/إخفاء زر "اللقاءات المباشرة" 🎥

### 4. **إعادة الاختبار** (`canRetakeQuiz`)
- **الوصف:** السماح للطالب بإعادة الاختبار عند الرسوب
- **التأثير:** إظهار/إخفاء زر "إعادة الاختبار" 🔄

### 5. **عرض الحلول** (`canViewSolutions`)
- **الوصف:** السماح للطالب بعرض حلول التمارين
- **التأثير:** إظهار/إخفاء زر "عرض الحل" 📖

### 6. **تحميل الشهادات** (`canDownloadCertificates`)
- **الوصف:** السماح للطالب بتحميل الشهادات والوثائق
- **التأثير:** إظهار/إخفاء زر التحميل 📜

## 🔧 الإعدادات الافتراضية

عند أول تشغيل للنظام، يتم تفعيل جميع الصلاحيات افتراضياً:

```typescript
{
  teacher: {
    canManageAcademicSettings: true,
    canEditGeneralSettings: true,
    canManageContent: true,
    canCreateParents: true,
    canEditParents: true,
    canDeleteParents: true,
    canCreateStudents: true,
    canEditStudents: true,
    canDeleteStudents: true,
    canViewReports: true,
    canManageQuizzes: true,
  },
  parent: {
    canCreateStudents: true,
    canEditStudents: true,
    canDeleteStudents: false, // معطلة افتراضياً
    canViewReports: true,
    canChangeGrade: false, // معطلة افتراضياً
    canChatWithSupport: true,
  },
  student: {
    canChangeGrade: false, // معطلة افتراضياً
    canAccessChat: true,
    canAccessLiveMeeting: true,
    canRetakeQuiz: true,
    canViewSolutions: true,
    canDownloadCertificates: true,
  },
}
```

## 🎨 تجربة المستخدم

### عند تعطيل صلاحية:
1. **الأزرار/الخيارات:** تختفي من الواجهة
2. **محاولة الوصول المباشر:** تظهر رسالة واضحة:
   ```
   🔒 لا توجد صلاحية
   عذراً، ليس لديك صلاحية الوصول إلى هذه الميزة.
   يرجى التواصل مع المشرف للحصول على الصلاحيات اللازمة.
   ```
3. **الحماية على مستوى الكود:** فحص الصلاحيات قبل تنفيذ أي عملية

## 🔍 كيفية الاستخدام للمطورين

### استيراد دوال فحص الصلاحيات:
```typescript
import { 
  hasTeacherPermission, 
  hasParentPermission, 
  hasStudentPermission,
  getTeacherPermissions,
  getParentPermissions,
  getStudentPermissions
} from '../../permissions';
```

### مثال للاستخدام:
```typescript
// فحص صلاحية واحدة
if (hasTeacherPermission('canManageContent')) {
  // عرض محتوى إدارة المحتوى
}

// الحصول على جميع الصلاحيات
const permissions = getTeacherPermissions();
if (permissions.canCreateParents) {
  // عرض زر إضافة ولي أمر
}
```

## 🎯 سيناريوهات الاستخدام

### سيناريو 1: تقييد المعلمين الجدد
```
المشكلة: معلم جديد لا نريده أن يحذف بيانات
الحل: تعطيل canDeleteParents و canDeleteStudents
النتيجة: المعلم يمكنه الإضافة والتعديل فقط
```

### سيناريو 2: تقييد إنشاء الحسابات
```
المشكلة: نريد أن يكون المشرف فقط من يضيف الحسابات
الحل: تعطيل canCreateParents و canCreateStudents للمعلمين
النتيجة: لا يمكن للمعلمين إضافة حسابات جديدة
```

### سيناريو 3: تعطيل الدردشة للطلاب
```
المشكلة: نريد تركيز الطلاب على الدراسة فقط
الحل: تعطيل canAccessChat للطلاب
النتيجة: اختفاء أيقونة الدردشة من واجهة الطالب
```
