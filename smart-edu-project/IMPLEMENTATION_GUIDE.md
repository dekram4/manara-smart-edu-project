# دليل التطبيق - منصة SmartEdu التعليمية

## مميزات النظام

### 1. إدارة حسابات المستخدمين

#### حسابات المشرف
- تسجيل دخول آمن
- إدارة شاملة لجميع مكونات النظام
- لوحة تحكم رئيسية بإحصائيات شاملة

#### حسابات أولياء الأمور
- تسجيل دخول بأسم المستخدم وكلمة المرور
- رقم هاتف فريد للربط مع الطلاب
- تغيير كلمة المرور عند أول دخول
- عرض جميع الأبناء المرتبطين بالحساب

#### حسابات الطلاب
- تسجيل دخول بأسم المستخدم أو رقم الهوية
- ربط تلقائي مع حساب ولي الأمر
- تحديث كلمة المرور من قبل ولي الأمر

### 2. ربط الطلاب بأولياء الأمور

عندما ينشئ المشرف طالباً:
1. يختار ولي الأمر من القائمة
2. يتم استخراج رقم هاتف ولي الأمر تلقائياً
3. يتم حفظ الربط ثنائي الاتجاه:
   - الطالب يحصل على `parentId` و `parentPhoneNumber`
   - ولي الأمر يحصل على الطالب في قائمة `children`
4. عند تسجيل دخول ولي الأمر، يرى جميع الطلاب المرتبطين

### 3. واجهة ولي الأمر

#### الميزات الرئيسية:
- **الشريط الجانبي الاحترافي**: عرض جميع الأبناء مع اسمهم والمادة الحالية
- **صفحة النظرة العامة**: 
  - بطاقة ملف شخصي جميلة للطالب
  - عرض جميع المواد الدراسية
  - إحصائيات الأداء لكل مادة
  - رابط تغيير كلمة المرور

- **صفحة تفاصيل المادة**:
  - إحصائيات شاملة (المعدل، أعلى درجة، أقل درجة)
  - رسم بياني لمستوى الأداء
  - قائمة تفصيلية بنتائج الاختبارات
  - خيار طباعة التقرير

- **إضافة طالب جديد**:
  - من واجهة ولي الأمر مباشرة
  - تحديد جميع معلومات الطالب الأساسية

### 4. واجهة الطالب

#### ميزات التعلم:
- **محتوى تفاعلي**: شرح الدروس مع رسوميات جميلة
- **تغيير المواد**: زر في الشريط الجانبي لتغيير الصف/المادة/الترم/الفصل/الوحدة
  - نافذة اختيار احترافية مع dropdowns
  - حفظ الاختيار تلقائياً
  - تحميل المحتوى الجديد فوراً

- **حل المشاكل**: 
  - إدخال سؤال مخصص
  - الحصول على حل مفصل من نموذج الذكاء الاصطناعي

- **الاختبارات**:
  - اختبارات متعددة الخيارات
  - أسئلة منتجة من قبل المشرف
  - أسئلة منتجة بالذكاء الاصطناعي
  - عرض النتائج الفوري

### 5. إدارة المحتوى من قبل المشرف

#### إعدادات الموضوعات:
- إدارة الصفوف
- إدارة المواد
- إدارة الترمات
- إدارة الوحدات
- إدارة الأترام (الفترات الزمنية)

#### إدارة الدروس:
- إضافة محتوى تعليمي جديد
- ربط المحتوى بصف/مادة/ترم/فصل/وحدة محددة
- تعديل وحذف المحتوى

#### إدارة الاختبارات:
- **الوضع اليدوي**: 
  - إضافة أسئلة يدوياً
  - تحديد الإجابة الصحيحة
  
- **الوضع الذكي**:
  - إدخال نص الدرس
  - إنتاج أسئلة اختبارية اعتماداً على Google Gemini API
  - حفظ الأسئلة تلقائياً

### 6. نموذج البيانات

#### STUDENTS (الطلاب):
```typescript
{
  id: string;                    // معرّف فريد
  name: string;                  // الاسم الكامل
  username: string;              // اسم المستخدم (مثل: student_123)
  password: string;              // كلمة المرور
  studentIdNumber: string;       // رقم الهوية
  parentPhoneNumber: string;     // رقم هاتف ولي الأمر
  parentId: string;              // معرّف ولي الأمر
  grade: string;                 // الصف (مثل: السادس)
  subject: string;               // المادة (مثل: اللغة العربية)
  atram: string;                 // الترم
  term: string;                  // الفصل
  unit: string;                  // الوحدة
  canChangeGrade: boolean;       // هل يمكن للطالب تغيير الصف
  createdAt: string;             // تاريخ الإنشاء
  lastActivity: string;          // آخر نشاط
}
```

#### PARENTS (أولياء الأمور):
```typescript
{
  id: string;                    // معرّف فريد
  name: string;                  // الاسم الكامل
  username: string;              // اسم المستخدم
  password: string;              // كلمة المرور
  phoneNumber: string;           // رقم الهاتف (فريد)
  children: StudentInfo[];       // قائمة الأبناء
}
```

### 7. سير العمل الشامل

#### سيناريو 1: المشرف ينشئ طالباً وربطه بولي أمر

1. المشرف يتوجه إلى "إدارة الطلاب"
2. يضغط على "إضافة طالب جديد"
3. يملأ البيانات:
   - الاسم
   - رقم الهوية
   - الصف
   - المادة
   - الترم، الفصل، الوحدة
   - كلمة المرور
   - **يختار ولي الأمر من القائمة** ← يتم استخراج رقم هاتفه تلقائياً
4. يضغط "حفظ"
5. الطالب يتم حفظه مع `parentPhoneNumber` تلقائياً

#### سيناريو 2: ولي الأمر يرى الطالب الجديد

1. ولي الأمر يتسجل دخول (أو كان مسجل دخول بالفعل)
2. الصفحة تتحقق من STUDENTS كل 2 ثانية
3. تجد الطالب الجديد بسبب تطابق `parentPhoneNumber`
4. يظهر الطالب في الشريط الجانبي تلقائياً

#### سيناريو 3: الطالب يغير المواد

1. الطالب يضغط على زر "تغيير المواد" في الشريط الجانبي
2. تظهر نافذة بقوائم منسدلة
3. يختار الصف والمادة والترم والفصل والوحدة
4. يضغط "تطبيق التغييرات"
5. يتم تحديث بيانات الطالب في localStorage
6. يتم تحميل المحتوى الجديد فوراً

### 8. المتطلبات التقنية

- **Node.js 18+**
- **npm 9+**
- **متصفح حديث** (Chrome, Firefox, Safari, Edge)
- **اتصال إنترنت** (لإنتاج الأسئلة بالذكاء الاصطناعي)

### 9. المكتبات المستخدمة

- **React 19.2.3**: إطار العمل الرئيسي
- **TypeScript ~5.8.2**: نوع الأمان
- **Vite 6.4.1**: أداة البناء
- **Tailwind CSS**: نمط الواجهة
- **@google/genai 1.34.0**: API الذكاء الاصطناعي

### 10. التخزين والبيانات

جميع البيانات تُحفظ في `localStorage`:
- `STUDENTS`: قائمة الطلاب
- `PARENTS`: قائمة أولياء الأمور
- `QUIZ_RESULTS`: نتائج الاختبارات
- `GRADES`: الصفوف المتاحة
- `SUBJECTS`: المواد المتاحة
- `ATRAMS`: الترمات المتاحة
- `TERMS`: الفصول المتاحة
- `UNITS`: الوحدات المتاحة
- `LESSON_CONFIGS`: المحتوى التعليمي
- `QUIZ_QUESTIONS`: أسئلة الاختبارات
- `smartEdu_activeParent`: ولي الأمر المسجل دخول
- `smartEdu_activeStudent`: الطالب المسجل دخول

### 11. الخطوات التالية المقترحة

1. **إضافة قاعدة بيانات حقيقية**: استبدال localStorage بـ Firebase أو MongoDB
2. **المصادقة الآمنة**: استخدام JWT tokens
3. **النسخ الاحتياطية**: نظام النسخ الاحتياطية التلقائية
4. **التقارير المتقدمة**: تحليلات أعمق لأداء الطلاب
5. **الإشعارات**: نظام الإشعارات الفورية
6. **واجهة التطبيق**: تطبيق موبايل native
