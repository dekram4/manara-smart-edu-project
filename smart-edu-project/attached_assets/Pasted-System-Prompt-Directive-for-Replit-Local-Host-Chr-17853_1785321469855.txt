System Prompt & Directive for Replit:

أهلاً. بعد معاينة مشروع الفلاتر الحالي على الـ Local Host/Chrome، تبين أن التطبيق يفتقر للعديد من المزايا والمنطق العملي (Logic) الذي تم الاتفاق عليه سابقاً، ويبدو بدائياً وغير مكتمل مقارنة بمتطلبات النظام القديمة.

المطلوب منك الآن هو إجراء إعادة هيكلة وتطوير شاملة لتطبيق Flutter ليتطابق بنسبة 100% مع النظام المطلوب من حيث: المنطق، البيانات، الواجهات، والـ Game Engine. يرجى الالتزام بالنقاط التالية:

1. الأعدادات الأكاديمية وإدارة المحتوى (Academic Settings & Content Hub):
عند حساب المشرف والمعلم: إعادة بناء قسم "الإعدادات الأكاديمية" ليشمل الهيكلية الكاملة (المراحل الدراسية، الصفوف، الفصول، المواد، الوحدات، والدروس).

إدارة المحتوى: تمكين المعلم والمشرف من إضافة، تعديل، حذف، وربط المحتوى التعليمي (أسئلة، اختبارات، دروس، ملفات وسائط) بنفس حقول ومنطق النظام القديم دون حذف أو اختصار أي حقل.

2. نظام الشهادات الشامل (Certificates Engine):
بناء وحدة كاملة لـ توليد وإصدار الشهادات (Certificate Generation) للطلاب عند إتمام المقررات أو المسابقات.

توفير شاشة عرض الشهادات (Preview) وخيارات الطباعة والتصدير (Print & PDF Export).

حفظ بيانات الشهادات وإصداراتها وتواريخها وتوقيعاتها بشكل متكامل مع قاعدة البيانات (Supabase).

3. التكامل والربط الكامل بين الأدوار والمنصات (Full Platform Integration):
ربط لوحات التحكم لجميع الأدوار (Admin/Supervisor, Teacher, Parent, Student) بحيث تعكس التغيرات فوراً عبر قاعدة البيانات (Real-time DB / Supabase Integration).

التأكد من أن ولي الأمر يرصد تقدم أبنائه الحقيقي، والمعلم يتابع طلابه، والمشرف يدير النظام بالكامل بنفس العلاقات والربط القديم (Relational DB Logic).

4. الجرافيك، الأنيميشن، وتجربة اللعب (Game Engine & Interactive UI/UX):
التصميم والواجهات: المظهر الحالي بدائي جداً. المطلوب تطوير واجهة جذابة تفاعلية احترافية (Modern Gamified UI).

محرك الألعاب والتفاعل (Gamification Engine): إضافة تأثيرات بصرية متحركة (Animations, Lottie, Confetti)، وأصوات تفاعلية (Sound Effects) عند كسب النقاط، حل الأسئلة، إكمال التحديات، وفتح الإنجازات.

استخدام الصور المتحركة والأيقونات التفاعلية لجعل تجربة الطالب مليئة بالحماس والتشويق (Gamified Learning Experience).

تنبيه هام للـ AI في Replit:
الرجاء عدم استخدام أي كود تعويضي مؤقت (Dummy/Placeholder code) أو اختصار الوظائف. اطلب منك كتابة المنطق كاملاً وحظر إنقاص الميزات المذكورة أعلاه. ابدأ بتعديل الملفات تدريجياً وأخبرني عندما تنتهي لتزويدي بالنسخة المحدثة.
