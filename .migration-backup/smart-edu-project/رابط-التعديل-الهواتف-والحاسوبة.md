# 🚀 دليل التثبيت على كافة الأجهزة - منارة MANARA SYSTEM

## 🍎 آيفون / آيباد / ماك (iOS & macOS Safari)

### الطريقة الأسهل: تثبيت PWA من Safari

1. فتح Safari على الهاتف/آيباد/ماك
2. انتقل إلى رابط الموقع المنشور
3. اضغط زر **شارك** (شروط Safari) في أسفل الشاشة
4. اختر **"إضافة إلى الشاشة الرئيسية"** (Add to Home Screen)
5. ستظهر أيقونة MANARA على شاشتك كتطبيق أصيلي!
6. افتحها تظهر بلا شروط Safari (نموذج standalone)

### الطريقة الأحترافية: بناء IPA (يحتاج macOS)

لبناء ملف IPA للتثبيت الأصيلي على الآيفون/آيباد:
1. نقل ملفات مشروع `ios/App` إلى جهاز macOS
2. افتح Xcode
3. افتح `ios/App/App.xcworkspace`
4. اضغط **Product > Archive**
5. وزع الارشفة في App Store Connect أو المعيد المباشر

## 📱 أندرويد (Android)

### طريقة 1: تثبيت PWA من Chrome

1. فتح Chrome على الهاتف/جهازك
2. انتقل إلى الموقع
3. اضغط القائمة (ثلاث نقاط علوية) في زاوية Chrome
4. اختر **"Install app"** أو **"إضافة إلى الشاشة الرئيسية"**
5. ستظهر أيقونة MANARA تعمل كتطبيق أصيلي

### طريقة 2: تثبيت APK مباشرة

1. انقل ملف `MANARA-Android.apk` إلى هاتفك
2. فعّل إعدادات > الأمان > المصادر غير المعروفة > شغّلها
3. انتقل إلى الحافظة واضغط على الملف APK
4. اضغط **"تثبيت"** وستتم العملية

## 🔧 طريقة إعادة البناء من الصفر

إذا أردت تعديل الكود والتحديث:

```bash
# الويب
npm run build

# الأندرويد (npm run build + gradle)
bash build-android.sh

# مزامنة Capacitor مع الويب
npx cap sync
```

## ✅ ما تم إنجازه في هذا التحديث

- ضوء PWA كامل (منفيست، سيرفيس ووركر، أيقونات تلبيث)
- استقراء عمودي من الشاشة وعدم التكبير لتجربة تطبيق أصيلي
- فيديوهات تعليمية مع أيقونات YouTube
- كلام عربي تشجيعي للأطفال
- رؤوس دافئة لامسة-روز-بامباي
- إشعارات فورية للمشرف عند إضافة فيديوات جديدة
